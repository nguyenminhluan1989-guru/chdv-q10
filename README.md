# Tòa CHDV 11 phòng Quận 10

Landing page bán tòa căn hộ dịch vụ 11 phòng tại Quận 10: cho thuê nguyên tòa 5 năm, 100 triệu/tháng, giá 23,4 tỷ.

- `index.html`: trang hoàn chỉnh, ảnh đã nhúng sẵn. Form đăng ký gửi lead về Google Sheet qua Apps Script.
- `images/mat-tien.jpg`: ảnh hiển thị khi chia sẻ link.

Host bằng GitHub Pages: Settings > Pages > Branch `main`, thư mục `/ (root)`.
